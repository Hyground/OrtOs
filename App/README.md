# App

## Qué hay aquí

Una aplicación Android mínima escrita en Kotlin. `MainActivity` muestra un texto de ejemplo usando una vista nativa sencilla.

## Qué debería hacer

Esta carpeta debe contener la experiencia móvil: pantallas, navegación, estado, conexión con la API, recursos visuales y pruebas. Al crecer pueden añadirse paquetes `ui`, `data`, `domain` y `network`.

## Ejecutar

Abra esta carpeta en Android Studio y ejecute el módulo `app`. Si se trabaja por terminal, use el Gradle instalado localmente o genere el wrapper desde Android Studio.
