# Web

## Qué hay aquí

Una interfaz mínima con React y Vite. La pantalla consulta el endpoint de saludo de la API y muestra su respuesta.

## Qué debería hacer

Esta carpeta debe contener componentes, páginas, estilos, llamadas a la API, estado y pruebas del sitio web. Conforme crezca pueden añadirse carpetas `components`, `pages`, `services`, `hooks` y `assets`.

## Ejecutar

```powershell
npm install
npm run dev
```

La variable opcional `VITE_API_URL` permite cambiar la dirección de la API.
