# API

## Qué hay aquí

Una API REST mínima desarrollada con Spring Boot 3 y Java 21. El código se divide en configuración y controladores HTTP. Incluye el endpoint de ejemplo `GET /api/saludo` y una prueba básica.

## Qué debería hacer

Esta carpeta debe contener las reglas del servidor, endpoints, servicios, acceso a datos, seguridad y pruebas de la API. Conforme crezca, pueden añadirse paquetes `service`, `repository`, `model` y `dto`.
